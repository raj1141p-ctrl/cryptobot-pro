CryptoBot Pro Professional UI v5

A visual/professional upgrade of v4:
- Trading Terminal hero/header
- Signal confidence meter
- Signal reasoning panel
- Order-flow/depth presentation
- Market sentiment card
- Session statistics
- Keyboard shortcuts
- Live market strip
- Risk/system panels
- Paper trading only

The order-flow panel is explicitly illustrative and is not used for live orders.

Run:
    python server.py
Then open:
    http://localhost:8000

No live exchange orders are enabled.
